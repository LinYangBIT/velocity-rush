# Velocity Rush · 霓速

中文 WebGL 竞速游戏：九条原创路线、五种模式、手动转向、漂移集气、氮气加速和五位 AI 对手。使用本地打包的 Three.js，无需构建或联网加载依赖。

## 本地运行

需要 Python 3；开发检查另需 Node.js 18 或更新版本。

```sh
npm run dev
```

在系统浏览器打开 <http://127.0.0.1:4173/>。也可直接运行：

```sh
python3 scripts/serve.py
```

保留运行服务的终端；关闭服务后本地链接将失效。不要直接双击 `dist/index.html`，浏览器模块需要 HTTP 服务。没有密钥、账户或配置步骤；记录和设置保存在当前浏览器，不跨设备同步。

## 驾驶

| 操作 | 键盘 / 触屏 |
| --- | --- |
| 转向 | ← / → 或 A / D；触屏左右按钮 |
| 刹车 | ↓ 或 S；刹车按钮 |
| 漂移 | 方向 + Shift；方向 + 漂移按钮 |
| 氮气 | Space；N₂O 按钮 |
| 复位 | R；复位按钮 |
| 暂停 | Esc；右上角暂停 |

车辆自动加速，但弯道需要手动转向。先刹车降速再入急弯，出弯使用氮气。支持比赛中的弯道提示、独立音乐和音效音量、倒计时暂停与多指触控。建议手机横屏；触屏能力不依赖窗口宽度。

个人竞速和计时挑战为两圈，一圈冲刺为一圈，漂移积分为 90 秒，自由练习不限圈。复杂地图包括十一街区、秋山九曲、老街工坊、冰川回廊、赤岩迷峡及具有真正上下层交叉的云港天环。

## 音乐

内置两首原创合成配乐，首次有效点击、触摸或键盘操作自动启动；主动静音会保存。浏览器可能限制零交互播放。支持本地音频导入；可选平台播放器仅在用户选择后访问外站，未捆绑商业录音。

## 开发与验证

```sh
npm run check
npm test
npm run previews
```

`dist/` 包含可编辑的模块源码（不是压缩构建产物）。`tests/` 覆盖物理、路线连续性、高架与隧道净空及新输入/设置机制。完整画面和触屏、音频需在浏览器另行验收；自动测试不等于真机性能测试。

配乐重建：安装 Python 的 `numpy`、`scipy` 与系统 `ffmpeg` 后运行 `python3 scripts/build-bgm.py`。正常游玩无需这些工具。
